# MFRC522

I learned how to work with the MFRC522 (RFID-RC522) module and how it works
physically. I built a project that can write data to an RFID card and read it
back, and shows the result on an LCD. I studied how to use each SPI pin.

Note: the MFRC522 chip is designed for 3.3 V. My module also worked on 5 V,
but that is outside the specification and may damage your over time. My work maybe because it is not originall, and mb it is different verison'
